## Contributing

Thanks for your interest in contributing to this project. Quick guidelines:

- Run tests locally before submitting a PR: `pip install -r requirements.txt` then `pytest`.
- Keep changes small and focused; open a single PR per logical change.
- Write tests for new functionality and ensure CI passes.
- Follow existing code style and use the provided `scripts/cli.py` for manual runs.
- For significant changes, open an issue first to discuss the approach.

Maintainers will review and request changes if needed.
